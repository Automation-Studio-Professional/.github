## Field Note

Automation Studio Professional is easier to trust when the model stays smaller than the bench it came from. A named session shows which lab is active, the pins show which components you will move today, and the closing note tells the next person which circuit diagram drives the system simulation. That record is short on purpose: not a copy of every valve, only the path back to the lab model that is still open on the lab PC.

The same loop fits a student hydraulic bench, a client electric block, or a computer shared by two trainers. Open the last Automation Studio Professional session, confirm one animation view, and leave the model easier to read than you found it. Other programs stay where they are. Automation Studio Professional only holds the circuit diagram, the system simulation, and the handoff.

## One Real Pass

Pick a circuit that already has a name: a short hydraulic loop, an electric drive, or a mixed lab sheet. Open it in Automation Studio Professional, keep only those components on the board, and read one animation view you can point to. A pass is done when that view stays tied to the system simulation and the unused parts are no longer in the way. Automation Studio Professional does not need a full rebuild of the schematic before it is useful.

If the pass feels crowded, the sheet is too wide. Drop anything that belongs to a different lab and leave it out of this workspace. The next pass can have its own title. What matters is that this one stays readable from the first component to the last animation, with the summary still matching the lab model on the board.
